How it works

Temporal CNN → calibration → decision

Three convolution blocks learn motion patterns across nine sensor channels. A separate participant group fits temperature scaling. The service returns class probabilities and a review flag.

Model-only latency above excludes HTTP and preprocessing. Demo round-trip time includes the API request.
